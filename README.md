 Данный мессенджер работает только одной сети Wi-Fi либо проводного подключения.
 Если человек подключен к другой сети вы не сможете с ним связаться.
 Сначала распакуйте .7z архив в любое место
 Также для работы мессенджера необходим питон версии 3.9 - 3.12 (стабильная версия 3.12.10)
     Для запуска на Windows:
     Запустите install.py
     После успешной установки
     Дважды нажмите на ярлыки "Server" & "NedroGraph"
     После откроется окно с мессенджером

EN:
================================================================================
 This messenger only works on one Wi-Fi network or a wired connection.
 If a person is connected to another network, you will not be able to contact them.
 Unpack it .7z archive to any location
 The messenger also requires python versions 3.9 - 3.12 (stable version 3.12.10)
     To run on Windows.:
     Launch install.py
     After successful installation
     Double-click on the shortcuts "Server" & "NedroGraph"
     After the messenger window opens.
